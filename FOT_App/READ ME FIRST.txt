Oscillometry Measurement System
===============================

STARTING THE APP
----------------
Double-click the one for your computer:

  Windows:  Start FOT App (Windows).bat
  Mac:      Start FOT App (Mac).command
  Linux:    Start FOT App (Linux).sh

That's all. Nothing needs installing first.

The FIRST start takes a few minutes and needs internet: it downloads a private
copy of Python and the app's packages (using a small tool called uv). After that
the app starts in a few seconds, with or without internet.

The app opens in its own window. A black/terminal window opens too; leave it
open while you use the app. Closing the app window stops the app.

If the computer asks first:
  * Windows "Windows protected your PC": click "More info", then "Run anyway".
    Windows "Open File - Security Warning": click "Run".
  * Mac "can't be opened" / "not verified": open System Settings > Privacy &
    Security, scroll down, click "Open Anyway" next to the script's name.
    You only need to do this once.
  * Linux: if double-clicking opens the file as text, right-click it and choose
    "Run as a Program", or in a terminal run:  bash "Start FOT App (Linux).sh"

THE ARDUINO
-----------
Plug it in by USB; it is found automatically. If several devices are plugged in,
go to Calibrate Device and press "Search for devices". On Linux, if the device is
found but can't be opened, run once:
    sudo usermod -aG dialout $USER     (then log out and back in)

DATA
----
Patient records, test results and calibration files are kept in this folder, in
_internal/app_src (system.db and the data folder). Keep this folder; copy those
two if you move to a new copy of the app.

IF SOMETHING GOES WRONG
-----------------------
Take a screenshot of the black/terminal window and send it to whoever looks
after the app. The app also writes a log to _internal/app_src/data/desktop.log.
